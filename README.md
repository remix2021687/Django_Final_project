# Django Web Application - Final Project

Tento projekt je závěrečnou prací v rámci mého studia na **STEP IT Academy**, který byl ohodnocen známkou **Výborně**. Jedná se o webovou aplikaci postavenou na frameworku Django.

## 🛠 Použité technologie
* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, JavaScript React
* **Database:** SQLite (příprava pro přechod na PostgreSQL)
* **Verzování:** Git

## 🚀 Klíčové funkce
* Kompletní integrace Django frameworku (Models, Views, Templates).
* Práce s databázovými vztahy.
* Responzivní uživatelské rozhraní.

## 🎓 Kontext studia
Tento projekt vznikl během 198 hodin intenzivního odborného studia zaměřeného na Python Development a Front-End Web Development.
